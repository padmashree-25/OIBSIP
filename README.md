# Oasis Infobyte Web Development Internship - Level 2

## Overview

This repository contains my projects completed as part of the Oasis Infobyte Web Development Internship - Level 2. The projects demonstrate practical knowledge of HTML5, CSS3, and JavaScript through interactive and responsive web applications.

## Internship Details

- Organization: Oasis Infobyte
- Track: Web Development
- Level: Level 2
- Technologies: HTML5, CSS3, JavaScript

## Tasks Completed

### Task 1 - Calculator

A browser-based calculator developed to perform basic arithmetic operations.

Features:
- Addition, subtraction, multiplication, and division
- Numeric buttons and decimal point
- Equals button
- Clear and backspace functionality
- Division-by-zero error handling
- Sequential operator operations
- Responsive interface
- CSS Grid button layout
- JavaScript event listeners

Technologies:
- HTML5
- CSS3
- JavaScript

Folder: `WebDev-L2-Calculator`

### Task 2 - Tribute Page

A responsive tribute webpage dedicated to Dr. A. P. J. Abdul Kalam, presenting information about his life, achievements, and contributions.

Features:
- Subject name and tagline
- Prominent image
- Biography section
- Key achievements
- Timeline
- Quote section
- Multiple background sections
- Different typography styles
- Responsive layout

Technologies:
- HTML5
- CSS3

Folder: `WebDev-L2-Tributepage`

### Task 3 - To-Do Web App

TaskFlow is an interactive task management application designed to help users organize their daily tasks.

Features:
- Add new tasks
- Pending task list
- Completed task list
- Mark tasks as complete
- Move completed tasks back to pending
- Edit tasks
- Delete tasks
- Pending and completed task counters
- Task timestamps
- Empty-state messages
- LocalStorage persistence
- Responsive design
- Keyboard support

Technologies:
- HTML5
- CSS3
- JavaScript
- LocalStorage

Folder: `WebDev-L2-ToDoWebApp`

### Task 4 - Login Authentication System

SecureAuth is a client-side authentication system demonstrating user registration, login validation, protected dashboard access, and logout functionality.

Features:
- User registration
- Username and email validation
- Password validation
- Minimum 8-character password requirement
- At least one number in the password
- Confirm password validation
- Duplicate account detection
- Login authentication
- Generic invalid credential message
- SHA-256 password hashing using Web Crypto API
- Protected dashboard
- Session management using LocalStorage
- Logout functionality
- Show/hide password option
- Responsive design

Technologies:
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Crypto API

Folder: `WebDev-L2-LoginAuthentication`

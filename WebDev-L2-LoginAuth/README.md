# SecureAuth - Login Authentication System

## Project Overview

SecureAuth is a browser-based authentication system developed as part of the Oasis Infobyte Web Development Internship.

The application provides user registration, password validation, login authentication, protected dashboard access, and logout functionality.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Crypto API

## Features

- User registration
- Username and email fields
- Password validation
- Minimum 8-character password requirement
- At least one number required in the password
- Confirm password validation
- Duplicate username/email detection
- Login authentication
- Generic invalid credential message
- SHA-256 password hashing
- Protected dashboard
- Session management using LocalStorage
- Logout functionality
- Responsive design
- Show/hide password option
- Empty-field validation

# TaskFlow - To-Do Web App

## Project Overview

TaskFlow is a responsive browser-based To-Do Web App developed as part of the Oasis Infobyte Web Development Internship.

The application allows users to create, manage, edit, complete, and delete daily tasks in an organized interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

- Add new tasks
- Display pending tasks
- Display completed tasks
- Mark tasks as complete
- Move completed tasks back to pending
- Edit tasks inline
- Delete tasks
- Pending task count
- Completed task count
- Task timestamps
- Empty-state messages
- Data persistence using LocalStorage
- Responsive design for mobile and desktop screens
- Keyboard support using the Enter key
